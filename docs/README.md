# CreoBench Documentation

This directory contains the CreoBench documentation. Each page focuses on one
topic, beginning with the core concepts and gradually introducing the details
needed to configure, run, and interpret a load test.

If you are new to CreoBench, follow the pages in this order:

## Suggested Reading Order

1. **[Concepts](concepts.md)**: Learn how a load test works and how its main
   components fit together.
2. **[Load Profiles](load-profiles.md)**: Define the traffic pattern your test
   will generate.
3. **[Scripting](scripting.md)**: Understand how concurrent users are
   modelled.
4. **[Warmup](warmup.md)**: Configure a warmup phase before the main test.
5. **[Service Registry](service-registry.md)**: Declare the services under
   test.
6. **[Outputs](outputs.md)**: Learn how to interpret the CSV and console
   output.
7. **[Best Practices](best-practices.md)**: Apply practical guidance when
   designing and running tests.
8. **[CLI Reference](cli-reference.md)**: Find all available command-line
   flags and options.
9. **[Troubleshooting](troubleshooting.md)**: Diagnose common problems and
   find possible solutions.
