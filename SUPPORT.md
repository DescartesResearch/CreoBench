# Support

## Getting Help

If you have a question about using this project, please contact Yannik Lubas at [yannik.lubas@uni-wuerzburg.de](mailto:yannik.lubas@uni-wuerzburg.de).

Before requesting help, please check the project documentation and search existing GitHub issues. Your question may
already have been answered.

## Reporting Bugs and Requesting Features

GitHub Issues are used to track bug reports and feature requests.

This repository provides issue templates for:

- Bug reports
- Feature requests

Please select the appropriate template when opening an issue and provide as much relevant information as possible.

Before opening a new issue:

1. Search the existing issues to check whether your problem or request has already been reported.
2. If a matching issue exists, add any relevant information to it instead of opening a duplicate.
3. If no matching issue exists, open a new issue using the appropriate template.

When reporting a bug, include:

- A clear description of the problem
- Steps to reproduce it
- The expected and actual behavior
- Relevant error messages or logs
- Your operating system, environment, and project version
- A minimal reproducible example, if applicable

When requesting a feature, explain the problem it would solve and describe the proposed behavior or workflow.

## Support Policy

This project is a research tool, and support is provided on a best-effort basis. Response times are not guaranteed, and
support may be limited by the availability of the maintainers.
